2025.03 – 현재

Vue 3 SPA + Spring Boot 멀티모듈 MSA

역할
프론트/백엔드 풀스택
  • AI 채팅·문서 서비스 설계·운영 — 레거시 채팅을 SSE 스트리밍 구조로 재설계하고, 멀티 Provider LLM 라우팅·인라인 인용·문서 스튜디오·유저 메모리를 프론트·백엔드로 구현해 프로덕션 운영.
  • 대민 게스트 인증 — Keycloak Token Exchange로 비로그인 사용자 온보딩(게스트 확인·생성 + JWT 발급) 구현.
  • 운영 장애 근본 대응 — 메모리 누수(jmap 진단)·세션 만료 401·쿠키 400·IDOR 등을 원인까지 규명해 해결.
세부 구현 7가지
  • AI 채팅 v2 재설계 — plex-server 경유 SSE 스트리밍 전면 전환. message_start·text_delta·thinking_delta·citation_delta·tool_calls·tool_results 등 이벤트 10종+ 직접 작성, Redis Pub/Sub 세션 상태 + 재연결 replay(멀티 인스턴스 HA).
  • 멀티 Provider LLM 라우팅 — Gemini/Bedrock/OpenAI/Azure 단일 추상화 라우팅·폴백(CircuitBreaker). 업무보고 자연어 파싱 엔진(청크 분할·LLM drop 진단).
  • 인라인 인용·문서 스튜디오·유저 메모리 — (DOC N) 인용 마커 문장별 주입·칩/카드·ECharts 차트, docsStudio v2 스트리밍(resume/stop·도구 세그먼트 렌더), 유저 메모리 운영 오픈.
  • 운영 안정성(근본 진단) — jmap 생존객체 분석으로 Keycloak deployment 메모리 누수(요청마다 재생성) 규명→realm 캐시 수정, 세션 만료 401 화면 갇힘→재로그인 유도·재포커스 선제 갱신, 쿠키 400 앱 단독 해결, bb8-logger 16MB 덤프·IDOR 차단.
  • 문서 변환 서버(doconverter) — 13개 타입 변환기, PDFBox 손상 PDF 복구·PDF→PDF 정규화, Playwright HTML→PDF·원본 레이아웃 보존, HWP/HWPX는 rhwp(Rust) 네이티브 벡터 렌더(검색 가능 PDF)·LibreOffice 폴백.
  • 통합 검색(server) — 문서·디렉터리 교차 검색을 단일 API로 통합(파일 타입 필터·즐겨찾기·JWT 토큰 파싱·저장 용량 집계), 핵심 로직 직접 구현.
  • 인프라 — WebClient로 12개+ 외부 MSA 게이트웨이·JWT 전파, Spring Batch DB cron 스케줄러(무중단 스케줄 변경), EKS·Jenkins·Harbor·Vault 운영.
